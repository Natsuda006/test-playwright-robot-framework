## ส่วนที่ 1: แผนการทดสอบ (Test Plan)

### 1.1 วัตถุประสงค์ของการทดสอบ (Objectives)
เพื่อรับประกันคุณภาพของระบบ T-Check ในส่วนผู้ดูแลระบบ โดยเน้นการทดสอบการทำงานผ่านหน้าจอแสดงผล (End-to-End User Interface Testing) และ API ที่เกี่ยวข้อง เพื่อยืนยันว่าปุ่มกด ช่องค้นหา ตัวกรอง การ์ดแสดงผล และการแจ้งเตือนต่างๆ ทำงานได้อย่างถูกต้อง แม่นยำ และสอดคล้องกับความต้องการของผู้ใช้

### 1.2 ขอบเขตการทดสอบ (Test Scope)
- **US-15 แดชบอร์ดผู้ดูแลระบบ:** การ์ดสรุปสถิติ 8 รายการ, กราฟสถิติย้อนหลัง 7 วัน, ตารางผู้ใช้ล่าสุด, และการจัดการข้อผิดพลาดเมื่อโหลดหน้าเว็บ
- **US-16 การจัดการผู้ใช้งาน:** ค้นหาผู้ใช้จากชื่อ/อีเมล, กรองระดับสิทธิ์สมาชิก, เปิดหน้ารายละเอียดผู้ใช้, แก้ไขและอัปเดตสิทธิ์ผู้ใช้, ระงับบัญชี/ปลดระงับบัญชี, และตรวจสอบ Pop-up ยืนยันการลบบัญชี
