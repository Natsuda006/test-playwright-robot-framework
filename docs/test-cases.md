## 1. ขอบเขตการทดสอบ (Scope)
เอกสารนี้ใช้สำหรับทดสอบฟีเจอร์เกี่ยวกับผู้ดูแลระบบผ่านหน้าจอแสดงผล (User Interface) และ API โดยมุ่งเน้นการทดสอบอัตโนมัติ (Automated Testing) ด้วย Playwright และ Robot Framework ครอบคลุม:
- **UC-15 / US-15 (ดูแดชบอร์ดผู้ดูแลระบบ):** ครอบคลุมการแสดงข้อมูลสรุปภาพรวม กราฟสถิตยิ้อนหลัง 7 วัน ตารางผู้ใช้งานล่าสุด และสถานะการแสดงผลข้อมูลบนหน้าจอ
- **UC-16 / US-16 (จัดการผู้ใช้งาน):** ครอบคลุมการค้นหาผู้ใช้ การกรองสิทธิ์ การเปิดดูรายละเอียดผู้ใช้ การเปลี่ยนสิทธิ์การใช้งาน การระงับบัญชี (Ban) การยกเลิกระงับบัญชี (Unban) และการตรวจสอบหน้าต่างยืนยันการลบบัญชี

### TC-ADM-001: แสดงข้อมูลสรุปของ Admin Dashboard
- **อ้างอิง:** US-15 (15.1) / UC-15
- **ความสำคัญ / ประเภท:** สูง / Positive
- **เงื่อนไขตั้งต้น:** ผู้ดูแลระบบเข้าสู่ระบบสำเร็จและมีสิทธิ์เข้าถึงหน้า Dashboard (`/admin`)
- **ขั้นตอนการทดสอบ:**
  1. เปิดหน้าเว็บ `/admin`
  2. ตรวจสอบว่าหน้าจอแสดงหัวข้อ "แผงควบคุมผู้ดูแลระบบ"
  3. ตรวจสอบการแสดงผลการ์ดข้อมูลสรุปภาพรวมบนหน้าจอ ได้แก่ "ผู้ใช้งานทั้งหมด", "ผู้ใช้งานระดับ Pro", "ผู้ใช้ธรรมดา", "ผู้ใช้งานที่ถูกระงับ", "การเรียกใช้ AI (วันนี้)", "โทเค็นที่ใช้ไปวันนี้", "อัตราข้อผิดพลาด (Error Rate)" และ "เวลาตอบสนองเฉลี่ย"
- **ข้อมูลทดสอบ:** บัญชีผู้ดูแลระบบ (Admin)
- **ผลที่คาดหวัง:** ระบบแสดงหัวข้อ "แผงควบคุมผู้ดูแลระบบ" และแสดงการ์ดสรุปข้อมูลสถิติทั้ง 8 รายการครบถ้วน
- **ผลการทดสอบจริง:** ระบบแสดงหัวข้อแผงควบคุมผู้ดูแลระบบและการ์ดสรุปข้อมูลสถิติบนหน้าจอทั้ง 8 รายการอย่างถูกต้องครบถ้วน
- **สถานะ:**  **ผ่าน (Passed)**

### TC-ADM-USR-004: กำหนดสิทธิ์การใช้งานจริงตาม TARGET_ROLE
- **อ้างอิง:** US-16 (16.4) / UC-16
- **ความสำคัญ / ประเภท:** สูง / Positive
- **เงื่อนไขตั้งต้น:** เปิดหน้ารายละเอียดของผู้ใช้ "nan006" เรียบร้อยแล้ว
- **ขั้นตอนการทดสอบ:**
  1. ตรวจสอบค่าสิทธิ์ในกล่องเลือกระดับสมาชิก (Dropdown)
  2. หากค่าสิทธิ์ปัจจุบันไม่ตรงกับเป้าหมาย ให้คลิกเลือกสิทธิ์เป็น `TARGET_ROLE` (เช่น `user-pro`)
  3. กดปุ่ม "บันทึก"
  4. ตรวจสอบข้อความแจ้งเตือน "อัปเดตข้อมูลผู้ใช้สำเร็จ" ปรากฏบนหน้าจอ
  5. กดปุ่มรีโหลดหน้าเว็บ (Reload Page) เพื่อตรวจสอบว่าช่องเลือกระดับสมาชิกยังคงมีค่าเป็น `TARGET_ROLE`
  6. กลับไปยังหน้ารายการผู้ใช้งาน (`/admin/users`) พิมพ์ค้นหาชื่อ "nan006" แล้วตรวจสอบสิทธิ์ในตารางว่าแสดงเป็น `TARGET_ROLE`
- **ข้อมูลทดสอบ:** ชื่อผู้ใช้: `nan006`, สิทธิ์ที่เลือก: `user-pro` (หรือ `user-free`)
- **ผลที่คาดหวัง:** ปรากฏข้อความสำเร็จ และสิทธิ์การใช้งานของผู้ใช้เปลี่ยนเป็นสิทธิ์ที่เลือกจริงทั้งในหน้ารายละเอียดและในตารางรายการ
- **ผลการทดสอบจริง:** บันทึกสิทธิ์ใหม่ลงฐานข้อมูลจริง เมื่อรีโหลดและตรวจสอบในตารางรายการแสดงผลถูกต้อง
- **สถานะ:**  **ผ่าน (Passed)**

### TC-ADM-USR-005: ระงับบัญชีผู้ใช้งานด้วยข้อมูลจริง
- **อ้างอิง:** US-16 (16.5) / UC-16
- **ความสำคัญ / ประเภท:** สูง / Positive
- **เงื่อนไขตั้งต้น:** เปิดหน้ารายละเอียดของผู้ใช้ "nan006" เรียบร้อยแล้ว (สถานะปกติ)
- **ขั้นตอนการทดสอบ:**
  1. ตรวจสอบช่องเลือก (Checkbox) ในส่วนหัวข้อ "ระงับบัญชีผู้ใช้"
  2. หากยังไม่ได้ถูกเลือก ให้คลิกทำเครื่องหมาย (Check) ในช่อง "ระงับบัญชีผู้ใช้"
  3. กดปุ่ม "บันทึก"
  4. ตรวจสอบข้อความแจ้งเตือน "อัปเดตข้อมูลผู้ใช้สำเร็จ" ปรากฏบนหน้าจอ
  5. เปิดไปยังหน้ารายการผู้ใช้งาน (`/admin/users`)
  6. พิมพ์ชื่อ "nan006" ในช่องค้นหา และตรวจสอบสถานะในตารางว่าแสดงข้อความ "ถูกระงับ (Banned)"
- **ข้อมูลทดสอบ:** ชื่อผู้ใช้: `nan006`, การติ๊กทำเครื่องหมายระงับบัญชี
- **ผลที่คาดหวัง:** แสดงข้อความ "อัปเดตข้อมูลผู้ใช้สำเร็จ" และในตารางรายชื่อผู้ใช้ สถานะเปลี่ยนเป็น "ถูกระงับ (Banned)"
- **ผลการทดสอบจริง:** เปลี่ยนสถานะผู้ใช้ "nan006" เป็น "ถูกระงับ (Banned)" ในตารางหน้ารายการผู้ใช้งานถูกต้อง
- **สถานะ:**  **ผ่าน (Passed)**

  3. กดปุ่ม "บันทึก"
  4. ตรวจสอบข้อความแจ้งเตือน "อัปเดตข้อมูลผู้ใช้สำเร็จ" ปรากฏบนหน้าจอ

- **ข้อมูลทดสอบ:** ชื่อผู้ใช้: `nan006`, การนำเครื่องหมายระงับบัญชีออก
- **ผลที่คาดหวัง:** แสดงข้อความ "อัปเดตข้อมูลผู้ใช้สำเร็จ" และในตาราง สถานะกลับมาเป็น "ปกติ"

- **สถานะ:**  **ผ่าน (Passed)**

### TC-ADM-USR-007: ตรวจสอบหน้าต่างยืนยันการลบบัญชีและกดยกเลิก
- **อ้างอิง:** US-16 (16.7) / UC-16
- **ความสำคัญ / ประเภท:** กลาง / Positive
- **เงื่อนไขตั้งต้น:** เปิดหน้ารายละเอียดของผู้ใช้ "nan006" เรียบร้อยแล้ว
- **ขั้นตอนการทดสอบ:**
  1. เลื่อนหน้าจอลงมาที่ส่วนหัวข้อ "เขตอันตราย (ลบบัญชี)"
  2. กดปุ่ม "ลบผู้ใช้งานนี้ถาวร"
  3. ตรวจสอบการปรากฏของหน้าต่างยืนยัน (Pop-up Dialog) และข้อความเตือน "ไม่สามารถย้อนกลับได้"
  4. กดปุ่ม "ยกเลิก" ภายในหน้าต่างยืนยัน
  5. ตรวจสอบว่าหน้าต่างยืนยันถูกปิดลง และหน้าจอยังคงแสดงรายละเอียดของผู้ใช้ "nan006" อยู่ โดยไม่เกิดการลบข้อมูลจริง
- **ข้อมูลทดสอบ:** ชื่อผู้ใช้: `nan006`, Action: คลิก ลบผู้ใช้งานนี้ถาวร -> กดยกเลิก
- **ผลที่คาดหวัง:** Pop-up แสดงขึ้นมาพร้อมคำเตือน และเมื่อกดยกเลิก หน้าต่างปิดลงโดยไม่มีการลบข้อมูล
- **ผลการทดสอบจริง:** แสดงหน้าต่าง Pop-up ถูกต้อง และเมื่อกดยกเลิก ผู้ใช้ "nan006" ยังคงอยู่ในระบบครบถ้วน
- **สถานะ:**  **ผ่าน (Passed)**
