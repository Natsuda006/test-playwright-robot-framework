## 1. ภาพรวมโครงการ (Project Overview)
โครงการ **T-Check** (ระบบตรวจสอบและแก้ไขคำผิดด้วย AI) พัฒนาขึ้นเพื่อช่วยผู้ใช้งานในการตรวจสอบ ปรับแก้ และแนะนำคำผิดในภาษาไทยอย่างถูกต้อง รวดเร็ว และมีประสิทธิภาพ สำหรับส่วน**ผู้ดูแลระบบ (Admin Subsystem)** มีวัตถุประสงค์เพื่อติดตามการใช้งานภาพรวมของระบบ ตรวจสอบสถิติการใช้งาน และบริหารจัดการสิทธิ์บัญชีผู้ใช้งานผ่านส่วนต่อประสานผู้ใช้ (User Interface) ได้อย่างครอบคลุม

---

## 2. ขอบเขตระบบส่วนผู้ดูแลระบบ (System Scope)
ระบบประกอบด้วย 2 ฟังก์ชันหลักสำหรับการทำงานของผู้ดูแลระบบ ดังนี้:

### 2.1 แดชบอร์ดผู้ดูแลระบบ (Admin Dashboard - US-15 / UC-15)
หน้ารายงานผลภาพรวมการทำงานของระบบ แสดงผลสถิติและข้อมูลเรียลไทม์ผ่านองค์ประกอบหน้าจอ ได้แก่:
- **การ์ดสรุปข้อมูลภาพรวม 8 รายการ:** ผู้ใช้งานทั้งหมด, ผู้ใช้งานระดับ Pro, ผู้ใช้ธรรมดา, ผู้ใช้งานที่ถูกระงับ, การเรียกใช้ AI (วันนี้), โทเค็นที่ใช้ไปวันนี้, อัตราข้อผิดพลาด (Error Rate) และเวลาตอบสนองเฉลี่ย
- **กราฟสถิติย้อนหลัง 7 วัน:** แสดงกราฟปริมาณการใช้โทเค็น และกราฟจำนวนการตรวจสอบคำผิดย้อนหลัง 7 วัน
- **ตารางผู้ใช้งานล่าสุด:** แสดงรายชื่อผู้ใช้งานที่มีความเคลื่อนไหวล่าสุด พร้อมข้อมูลสิทธิ์และโทเค็นที่ใช้ไป
- **ระบบจัดการการแสดงผลเมื่อเกิดข้อผิดพลาด:** ปรับปรุงการแสดงผลหน้าจอให้ทำงานได้อย่างต่อเนื่องโดยไม่มี Pop-up รบกวนเมื่อการเชื่อมต่อขัดข้อง

### 2.2 การจัดการผู้ใช้งาน (Admin User Management - US-16 / UC-16)
หน้าสำหรับการบริหารจัดการบัญชีและกำหนดสิทธิ์ผู้ใช้งานในระบบ ได้แก่:
- **การค้นหาผู้ใช้:** ค้นหาผู้ใช้จากชื่อบัญชีหรืออีเมล (เช่น `nan006`)
- **การกรองสิทธิ์:** คัดกรองรายชื่อผู้ใช้งานตามสิทธิ์สมาชิก (`user-pro` หรือ `user-free`)
- **การเปิดดูรายละเอียดผู้ใช้:** เข้าดูหน้ารายละเอียดเชิงลึกเฉพาะรายบุคคลตาม ID ผู้ใช้
- **การเปลี่ยนสิทธิ์การใช้งาน:** ปรับเปลี่ยนระดับสิทธิ์สมาชิกและบันทึกข้อมูลลงระบบฐานข้อมูลจริง
- **การระงับและปลดระงับบัญชี:** สลับสถานะระงับบัญชีผู้ใช้ (Banned) และคืนสถานะปกติ
- **การจัดการหน้าต่างยืนยันการลบบัญชี:** ตรวจสอบหน้าต่าง Pop-up เตือนความเสี่ยงในการลบบัญชีถาวร และฟังก์ชันกดยกเลิก

## 3. ผังกระบวนการทำงานของผู้ใช้ (User Flow & UI Process)

| ลำดับ | หน้าจอ (Screen / Route) | รายละเอียดการทำงานบนหน้าจอ |
| :---: | :--- | :--- |
| **1** | `/admin` (Dashboard) | เข้าสู่หน้าหลักผู้ดูแลระบบ ตรวจสอบการ์ดสรุปสถิติ 8 รายการ กราฟ 7 วันย้อนหลัง และตารางผู้ใช้ล่าสุด |
| **2** | `/admin/users` (User List) | ค้นหาชื่อผู้ใช้ `"nan006"`, กรองระดับสิทธิ์ `"user-pro"`, ตรวจสอบสถานะบัญชี `"ปกติ"` หรือ `"ถูกระงับ"` |
| **3** | `/admin/users/[id]` (User Detail) | แก้ไขสิทธิ์ในกล่อง Dropdown, ติ๊ก/ปลดติ๊กช่องระงับบัญชี, กดปุ่ม "บันทึก" และทดสอบปุ่มลบบัญชีถาวร (พร้อมกดยกเลิก) |
